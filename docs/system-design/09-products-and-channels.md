# 产品与渠道

> 设计状态：已实施首期模型  
> 管理员端一级菜单：产品与渠道。

## 1. 核心关系

**已确认**：尾程渠道仅区分承运商类型；一个供应商连接代表一套真实接口、账号与环境；服务固定绑定供应商连接。

```text
尾程渠道（FedEx / UPS / DPD）
└── 供应商连接（官方、代理或中转；一条记录即一套账号/环境/接口）
    ├── 服务 A
    ├── 服务 B
    └── 服务 C
```

约束：

- 一个尾程渠道可以有多个供应商连接；
- 一个供应商连接可以对应多个服务，每个服务只能绑定一个供应商连接；
- 下单时用户选择服务，后端根据服务找到供应商连接及其尾程渠道，再调用对应接口驱动；
- 服务不能在前端直接指定其他供应商连接或渠道。

尾程渠道承载承运商分类；供应商连接承载接口驱动、账号 profile、运行环境及业务参数；服务承载面向下单、计价和报价的业务规则。底层接口驱动保持可插拔，以支持官方、第三方和中转站接口。

## 2. 尾程渠道与供应商连接

尾程渠道只需要管理员填写名称，系统自动生成不可变内部编号，例如 `FEDEX`、`UPS`、`DPD`。供应商连接表示一个已配置好的实际打单连接，至少包含：

- 所属尾程渠道；
- 供应商连接编号和名称；
- 对接驱动／接口类型；
- 接口账号和运行环境；
- 启用状态；
- 接口健康状态与最近调用结果；
- 备注。

接口密钥、账号和 URL 仅保存在后端本地忽略的配置文件，页面不得向任何用户展示密钥原文。供应商连接的业务参数则由驱动 schema 预定义并保存在数据库。已被服务、成本表或账单引用的供应商连接不能删除，只能停用。

## 3. 服务

一个服务必须关联一个已启用供应商连接，并可细化以下配置：

| 配置项 | 说明 |
|---|---|
| 可发往国家 | 服务允许寄送的国家范围 |
| 计费方式 | 重量、体积、实重与材积重取大值 |
| 计重方式 | 按票、按箱 |
| 体积计算方式 | 具体规则待细化 |
| 尺寸精度 | 长、宽、高的数据保留精度 |
| 币种 | EUR或GBP |
| 对应供应商连接 | 服务固定绑定的供应商连接及其尾程渠道 |
| 计抛系数 | 计算材积重时使用 |
| 支持清关方式 | 可用于该服务的清关选项 |
| 支持交货条款 | 可用于该服务的交货条款选项 |
| 计费重小数位 | 最终计费重量的保留或进位精度 |
| 票计重精度 | 按票计重时的重量精度 |
| 一票多件 | 是否允许一个订单包含多个箱号／件数 |
| 最小件数 | 订单允许的最少箱数／件数 |
| 最大票实重 | 单票允许的最大实际重量 |
| 可选附加费 | 可应用于该服务的燃油费、超重费、偏远地区费；偏远地区费启用时选择一个偏远地址模板并设置收费金额 |

服务还应具备服务编号、服务名称、启用状态、创建时间和修改时间。服务停用后不得用于新下单，但历史订单仍保留服务快照。

### 3.1 一票多件能力

服务必须配置是否支持一票多件：

```text
仅支持一票一件：订单箱数必须为 1
支持一票多件：订单箱数受服务最小件数及其他限制控制
```

该规则由后端在人工创建、Excel导入和开放API创建时统一校验，不能只依赖前端隐藏“新增箱号”按钮。

### 3.2 已确认的计算基础

- 全系统重量单位统一使用 `kg`；
- 全系统尺寸单位统一使用 `cm`；
- 计费方式固定为以下三种之一：

```text
重量
体积
实重与材积重取大值
```

- 国家组需要支持，但仅维护欧洲国家范围内的国家组；
- 同一尾程渠道可以建立多个供应商连接，例如不同账号、接口版本、测试环境或生产环境；
- 每个服务仍固定绑定其中一个供应商连接。

体积计费、材积重和实重取大值服务在预扣阶段如何使用用户预估重量与尺寸、在最终对账阶段如何使用供应商返回实重，需与报价计算规则一并确定。

### 3.2 已确认的预扣计算

- 体积计费：`长 × 宽 × 高 ÷ 1,000,000`，得到 `m³`，再按报价表中的每立方米价格计算；
- 实重与材积重取大值：预扣阶段取“用户填写的预估收费重”与“系统根据尺寸计算的材积重”二者中的较大值，再按报价表计算预扣金额；
- 供应商返回实重和最终收费重后，不覆盖预扣依据，而是进入会计实际对账。

按票计重的服务，使用订单层面的计费重量 `W` 参与报价表匹配。UPS类报价表中的 `0–30kg` 仅为一个实例；不同服务、不同供应商渠道或不同版本的UPS报价表可配置不同区间与超阈值。最低收费按箱生效，整票最终价格不低于“每箱最低收费 × 箱数”。

按箱计重的服务，对每个箱号独立计算区间价或每公斤价，再逐箱应用最低收费，最后汇总为订单价格。

### 3.3 服务附加费能力

服务可选择启用以下附加费能力：

- 燃油费（尾程渠道级）；
- 超重费用；
- 偏远地区费用。

服务决定偏远和超重等服务级附加费是否适用；燃油费则由尾程渠道统一维护。同一尾程渠道下的全部供应商连接与服务自动继承同一燃油费率。渠道详情可设置多个不重叠的生效开始／结束日期区间，通常每周维护一条，也可提前维护未来周期；试算只取下单当日命中的唯一费率，未命中时燃油费为 0。先由供应商基础成本加服务利润形成基础客户运费，再加上命中的附加费；附加费不参与利润叠加。订单价格在下单和对账时保存明细快照。

偏远地区费为服务级配置：服务勾选“收取偏远地区费”后，必须选择**一个**可复用的邮编规则模板，并填写该服务的偏远地区收费金额；未勾选则不匹配偏远规则、不收取该费用。偏远地址模板在报价管理中维护，可供多个服务复用。偏远费仅作为客户应收收费项，不在供应商成本表中单独配置或计入供应商应付成本。超重费用通过按服务配置的安全表达式判断并计算金额，分别在预扣阶段使用预估收费重、最终计算阶段使用供应商实重。

燃油费、偏远地区费、超重费用均在各自规则计算完成后立即按服务币种保留两位小数，再计入订单总价和费用明细；实现时统一采用十进制金额计算与标准四舍五入，避免浮点误差。

“超重费用”是服务的收费规则；它与订单标识中的“超重”（预估重量与供应商返回重量差异）是两个不同概念，必须分别管理。
