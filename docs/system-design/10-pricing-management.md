# 报价管理

> 设计状态：讨论中  
> 管理员端一级菜单：报价管理。

## 1. 基本规则

**已确认**：报价管理的成本与利润归属分开：

1. **成本表**：绑定供应商，记录供应商固定的应付成本；
2. **利润表**：绑定服务，记录服务面向客户报价时使用的利润规则。

订单创建时，系统通过服务固定关联的渠道找到供应商成本表，再匹配服务利润表计算客户预扣金额；供应商实重和最终收费重返回后，会计使用供应商成本表及供应商数据进行实际对账。

此前“成本表与服务绑定”的表述已由本规则替代。

报价计算需遵守服务的计费方式：重量、体积或实重与材积重取大值；重量和尺寸基础单位分别为 kg、cm。

体积计费按 `长 × 宽 × 高 ÷ 1,000,000` 得到 `m³` 后，乘以报价表中对应的每立方米价格。实重与材积重取大值服务在预扣阶段，采用用户预估收费重与系统材积重的较大值。

## 2. 价格快照原则

订单必须保存创建时使用的利润表、成本表、版本、币种和计算结果快照。后续修改价格表不得改变历史订单的预扣、应收、应付和利润记录。

### 2.1 版本与生效时间

**已确认**：同一服务的利润表、同一供应商的成本表均支持多个版本及生效时间。

每个版本至少包含：

- 归属对象：服务（利润表）或供应商（成本表）；
- 类型：利润表或成本表；
- 版本号；
- 生效开始时间；
- 生效结束时间，可选；
- 状态：草稿、待生效、生效中、已失效；
- 币种；
- 创建人、审核人及创建时间。

同一服务、同一适用范围、同一目标对象在同一时段不得存在两个生效版本。利润表首页以服务为入口；点击服务后在服务详情维护其多个版本、国家利润行及版本状态。

已生效版本允许直接修改价格行，但每次修改必须写入不可篡改的审计记录，保存修改前后内容、操作管理员和时间。需要保留旧商业规则时，仍建议新建版本并设置生效时间。

### 2.2 客户差异报价

**已确认**：客户报价支持按客户、客户等级或客户分组设置不同价格。

利润表需要配置适用范围：

```text
默认报价
客户等级报价
客户分组报价
指定客户报价
```

订单预扣时，系统根据订单服务和订单所属客户解析匹配的利润表。多个范围同时匹配时，优先级为：

```text
指定客户 > 客户分组 > 客户等级 > 默认报价
```

客户等级与客户分组均为后台自定义主数据；一个客户在任一时刻最多各归属一个等级和一个分组。归属更换时系统结束旧归属并保留生效起止历史。报价和会计重算按计费日期读取当日归属。

每个利润版本必须维护一条默认利润规则，并可按国家设置例外规则。命中较高优先级版本后，目的国存在例外时使用例外；未设置例外时使用该版本默认利润，不回退到低优先级报价。

利润版本可选择同一供应商连接的成本表作为矩阵来源。系统按成本表的国家／邮编列和重量段展示“成本 + 利润”的基础运费预览，并可导出 XLSX；挂号费、操作费、燃油和服务附加费不混入该利润矩阵。

### 2.3 客户报价与利润计算

**已确认**：客户最终报价基于供应商成本与服务利润计算：

```text
客户最终报价 = 匹配的供应商成本 + 服务利润
```

服务利润支持两种模式：

| 利润模式 | 计算公式 |
|---|---|
| 成本百分比 | 服务利润 = 匹配成本 × 利润百分比 |
| 固定加价 | 服务利润 = 针对匹配成本价格行配置的固定金额 |

利润表可以针对成本表中的不同国家、重量区间或其他成本价格行设置不同的百分比或固定加价。订单需快照匹配到的成本价格行、利润规则、利润金额和最终应收金额。

**已确认**：利润只基于供应商基础运费成本计算，不参与燃油、偏远、超重等附加费用的利润叠加。

完整报价顺序：

```text
1. 计算供应商基础运费成本
2. 按利润表计算服务利润
3. 基础客户运费 = 供应商基础运费成本 + 服务利润
4. 判断是否启用燃油费、偏远地区费、超重费用
5. 对每个已启用附加费判断触发条件
6. 将命中的附加费加入基础客户运费，得到客户最终报价
```

## 3. 供应商成本表、国家组与重量价格矩阵

**已实现（首期）**：供应商成本不再采用“成本版本 + 每国独立价格行”的录入界面，而是按以下关系维护：

```text
供应商连接
  └── 成本表（版本、有效期、适用重量／箱数、币种、状态）
        └── 国家组（国家表中的欧洲国家）
              └── 邮编价格列（国家 + 邮编规则 + 四项国家级费用 + 重量价格矩阵）
```

国家表预置欧洲国家，记录中文名称、ISO 两字代码和启用状态。成本表国家组可混用中文名和二字代码，并以空格分隔，例如 `比利时 BE 荷兰 NL`；系统会转为唯一的 ISO 代码。未知、重复或停用国家均不能用于新表。

成本表表头字段如下：

| 字段 | 说明 |
|---|---|
| 供应商连接 | 一张成本表只属于一套实际供应商连接 |
| 版本号与有效期 | 用于版本管理与生效匹配 |
| 国家组 | 该表允许的目的国集合 |
| 最小／最大重量 | 整票总计费重的适用范围 |
| 最小／最大箱数 | 整票总箱数的适用范围 |
| 币种 | 当前支持 EUR、GBP |
| 状态 | 正常或停用 |

同一供应商连接、国家、有效期内，重量和箱数适用范围不得重叠。下单试算按供应商连接、目的国、下单时间、整票总计费重和总箱数命中唯一的正常成本表。

价格在成本表详情中以 Excel 模板粘贴写入。标准模板为：

| 重量段 | 计价单位 | 法国 | 法国 | 荷兰 |
|---|---|---:|---:|---:|
| 0-1 | 按票 | 5.20 | 5.50 | 4.54 |
| 71.01+ | 每KG | 0.31 | 0.35 | 0.19 |
| 邮编开头 |  | （默认） | 75000 | （默认） |
| 最低票运费 |  | 0.00 | 0.00 | 0.00 |
| 最低箱运费 |  | 4.24 | 4.50 | 4.28 |
| 挂号费 |  | 0.00/票 | 0.00/票 | 0.00/票 |
| 操作费 |  | 0.00/KG | 0.00/KG | 0.00/KG |

`重量段` 支持 `0-20`、`20.01-30` 和 `30+`，其中 `0+` 会规范成 `0-1`；开放上限只能出现在最后一行。每个重量段独立选择 `按票`、`按箱` 或 `每KG`，因此同一表可混合固定区间价和超阈值每公斤价。下载模板默认使用国家表的中文名；导入时国家列可写中文名或 ISO 代码，且必须完整覆盖成本表国家组。同一个国家可重复出现，表示不同价格列，但每列必须拥有不同邮编规则。

邮编规则空白表示该国默认列；单个值表示去空格、转大写后的完整邮编匹配；`2000-2999` 表示仅数字邮编的闭区间匹配。具体规则优先于默认列；同国最多一个默认列，具体规则不得重复或重叠。若目的国和邮编没有唯一价格列，试算和创建订单均拒绝，不能回退到其他国家价格。

粘贴后先解析预览，只有所有校验通过才能写入。写入在一个事务中整表替换旧价格明细；任一国家列、金额、重量段或重叠校验失败时，旧价格保持不变。

首期只支持上述统一重量矩阵。不支持首重续重、围长／重量复合条件等 Epix 格式，也不支持按体积服务使用此成本表格式。

### 3.1 价格矩阵计算

对命中的重量段：

```text
按票：整票总计费重选段，收取一次固定金额
按箱：每箱按自己的计费重选段，逐箱应用最低箱运费后汇总
每KG：整票总计费重选段，单价 × 整票总计费重
基础成本先应用最低箱运费（按票／每KG时至少为最低箱运费 × 箱数），再应用最低票运费
挂号费按票加一次；操作费 = 整票最终计费重 × 每KG费率
```

服务利润只基于已完成最低箱和最低票保护的基础成本；挂号费、操作费不参与利润。订单费用明细会分别保存重量基础成本、最低箱调整、最低票调整、挂号费、操作费、服务利润及服务附加费。

### 3.2 三段式重量资费表示例

**已确认**：以UPS示例为代表的重量报价表包含三类价格模块：

1. **固定区间价**：例如 `0–2kg`、`2.01–5kg` 一直到 `25.01–30kg`，命中区间后按票收取固定金额；
2. **超阈值每公斤价**：例如重量大于 `30kg` 后，按整票总重量乘以对应国家的每公斤单价；
3. **最低收费**：报价表可定义最低应收金额，具体按票还是按箱应用待确认。

上述 `30kg` 仅是当前UPS报价表实例的阈值，不是系统固定规则。每张报价表可配置自身的重量区间、超阈值及每公斤价格。

对重量为 `W`、超阈值为 `T` 的订单，当前计算规则为：

```text
若 W ≤ T：
    基础价格 = 命中重量区间的固定票价

若 W > T：
    基础价格 = W × 对应国家的每公斤单价

最终价格 = 在基础价格上应用最低收费规则后的金额
```

例如，德国34kg的订单命中“>30kg 每公斤”模块，按整票 `34 × €0.39 = €13.26` 计算；不是先取30kg档位价格再加超出部分。

### 3.3 多箱订单规则

最低收费 `Minimum / Pkg` 按每个箱号生效。

**按票计重**：

```text
整票基础价格 = 根据整票计费重量匹配固定区间价，或整票重量 × 每公斤价
最低收费总额 = 每箱最低收费 × 箱数
整票最终价格 = max(整票基础价格, 最低收费总额)
```

**按箱计重**：

```text
每箱基础价格 = 根据该箱计费重量匹配固定区间价，或该箱重量 × 每公斤价
每箱最终价格 = max(每箱基础价格, 每箱最低收费)
订单最终价格 = 所有箱号最终价格之和
```

供应商成本表与服务利润表均可复用重量、体积、国家及附加费等计算基础；成本表保存供应商应付金额，利润表保存服务报价使用的利润规则。客户最终报价为匹配供应商成本加上服务利润。

## 4. 服务附加费

服务可选择超重费用和偏远地区费用；燃油费由其尾程渠道按日期区间统一配置。附加费按相应规则计算，订单总价为：

```text
订单总价 = 基础客户运费 + 所有命中的附加费
```

附加费需要独立生成订单费用明细，以支持客户预扣、会计对账、补扣／退款和供应商成本核对。

**已确认**：燃油费、偏远地区费和超重费用均在各自计算完成后，立即按订单服务币种保留两位小数；各项已舍入金额再参与订单总价汇总。金额计算使用十进制定点数，并采用标准四舍五入。

### 4.1 燃油费

**已确认**：燃油费按基础运费百分比计算。

```text
燃油费 = 基础客户运费 × 燃油费百分比
```

燃油费百分比随尾程渠道的生效日期区间维护。一个渠道可维护多条不重叠区间（通常按周），其全部供应商连接和服务在下单时共享当前日期命中的唯一费率；无命中区间时燃油费为 0。

### 4.2 偏远地区费用

**已确认**：偏远地区通过邮编规则识别，并支持创建可复用的“偏远地区模板”应用到不同服务。

```text
偏远地区模板
├── 适用国家或国家组
├── 邮编规则或邮编范围
└── 模板说明

服务
└── 最多应用一个偏远地区模板
```

模板负责判断地址是否偏远；服务勾选收取偏远地区费后，选择一个模板并设置偏远地区费用金额。收件地址命中该模板时，对该订单收取一次偏远地区费用；未勾选或未命中时不收费。偏远地址模板在报价管理中作为独立区域维护，可复用于多个服务。偏远费只产生客户应收费用明细，不在供应商成本表中单独配置，也不形成供应商应付偏远成本。

### 4.3 超重费用

**已确认**：超重费用允许管理员针对不同服务，在前端通过表达式配置判断条件与收费金额。

超重费用表达式采用受控规则引擎，不允许执行任意SQL或脚本。规则可访问服务允许的字段，例如预估收费重、供应商实重、最终收费重、箱数、尺寸和国家；规则结果返回“是否收费”及费用金额。

示例：

```text
supplier_actual_weight > 30
? (supplier_actual_weight - 30) * 1.50
: 0
```

**已确认**：超重费用分两阶段计算：

| 阶段 | 使用重量 | 处理方式 |
|---|---|---|
| 订单预扣 | 客户填写的预估收费重 | 运行预扣表达式并计入下单预扣金额 |
| 最终计算 | 供应商返回实重 | 运行最终表达式得到实际超重费用，进入实际对账 |

表达式需具备校验、样例测试、版本、生效时间和执行审计。供应商实重返回后算出的最终超重费用差额，须经会计确认后再补扣或退款。

## 5. 成本与利润表结构

| 层级 | 内容 |
|---|---|
| 成本表表头 | 供应商连接、版本、生效时间、国家组、重量／箱数范围、币种、最低箱收费、状态 |
| 利润表表头 | 服务、适用客户范围、版本、生效时间、币种、状态 |
| 成本价格矩阵 | 每个重量段的计价单位，以及每个国家对应价格 |
| 附加费规则 | 附加费类型、触发条件、计算方式、金额或比例 |

使用精确的最低／最高重量边界存储价格行，不在代码中写死 `2kg`、`30kg` 等阈值；不同服务可维护不同区间。
