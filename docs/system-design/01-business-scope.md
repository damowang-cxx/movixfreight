# 业务范围与核心概念

## 1. 系统定位

**已确认**：本系统不是单纯的面单打印工具，而是集以下能力于一体的物流业务平台：

- 中国至欧洲物流订单管理；
- UPS、FedEx、DHL 等尾程运单创建；
- 官方接口、第三方代理商接口、中转站接口统一接入；
- 面单获取、下载、打印、取消与异常处理；
- 客户余额、扣费与资金流水；
- 客户账单、供应商成本和对账管理。

## 2. 核心业务概念

为避免把实际承运商和接口提供方混为一体，使用以下领域概念：

| 概念 | 示例 | 说明 |
|---|---|---|
| 承运商 Carrier | UPS、FedEx、DHL | 实际承担尾程配送的物流公司 |
| 接口供应商 Supplier | UPS 官方、UPS 代理商 A、FedEx 中转商 B | 与平台发生接口和商务关系的供应方 |
| 对接驱动 Connector | UPS 官方协议、代理商 A 协议 | 后端实现具体接口协议的代码模块 |
| 供应商账号 Supplier Account | 某个 API 账号及密钥 | 供应商下的实际接口账号、环境和认证配置 |
| 供应商接口渠道 Channel | 某UPS代理商API账号 | 前端配置的供应商打单接口实例，可承载多个服务 |
| 服务 Service | 德国 UPS 经济线 | 前端可选择的业务服务；每个服务固定对应一个供应商接口渠道 |
| 物流订单 Shipment | 一票或一票多件货物 | 客户提交并由系统打单的业务对象 |

## 3. 当前范围

### 已确认纳入

- 两套前端：管理员网站和客户网站；
- 一个统一后端；
- 多供应商、可扩展接口对接；
- 客户 EUR、GBP 余额管理；
- 管理员人工增加或减少客户余额；
- 打单扣费；
- 账单管理。

### 后续逐项讨论

- 客户与子账号；
- 订单创建和批量导入；
- 地址与包裹校验；
- 供应商路由；
- 单票和一票多件；
- 面单格式及直接打印；
- 运单取消和退款；
- 客户价卡；
- 供应商成本；
- 附加费；
- 客户账单与供应商账单；
- API 与 Webhook；
- 管理员权限与审计。

### 暂不纳入

- 独立的“轨迹管理”一级菜单。物流信息仍作为订单详情的一部分，具体展示和同步范围在订单管理中讨论。
