# 待确认问题

本文件只收集尚未定案、会影响产品或技术实现的问题。确认后应将结论转入 `decisions.md`。

## 当前讨论：前端应用与账号权限

1. 客户企业能否自行创建和停用子账号？
2. 一个客户登录账号能否同时属于多家客户企业？
3. 首版界面是否只提供中文？
4. 哪些管理员角色可以调整客户余额？
5. 管理员网站是否强制双因素认证？
6. 管理员端和客户端分别需要何种移动端适配程度？

## 当前讨论：客户管理

1. 自助注册客户在“待审核”或“待核对充值”期间，是否允许登录查看审核进度？
2. 管理员核对充值时，是直接为客户执行余额入账，还是先审核后由财务另行入账？
3. 唯一API密钥在何时创建：客户启用时自动创建，还是管理员在客户详情中按需创建？
4. 客户是否可以自行创建、停用本企业的子账号？
5. 一个登录账号是否允许属于多家客户企业？
6. 低余额预警是否需要增加每日或每周的未处理提醒？

2. 左侧导航是否支持收缩成仅图标模式？
