## 2026-08-08：体积计费与材积重试算

- 计价引擎新增按体积计费：单箱体积统一用 `长(cm) × 宽(cm) × 高(cm) ÷ 1,000,000` 转为 m³；按票服务汇总体积后按每立方米价格取价，按箱服务逐箱取价，并复用每箱最低收费保护。
- “实重与材积重取大”服务现使用服务级计抛系数：按票时以预估收费重与全部箱子的材积重合计取大，按箱时逐箱以实重与材积重取大。新建此类服务必须填写大于 0 的计抛系数，管理端默认值为 5000，可按服务修改。
- 管理端、客户门户、订单预扣、Excel 导入预校验均向同一报价服务传递箱子尺寸；试算结果增加计费体积与实际采用的计费重，避免前端和下单预扣使用不同公式。
- 供应商成本表录入增加“每立方米成本”和“每箱最低收费”字段。重量区间价格与体积价格可同属一个国家成本行，未使用字段可留空。
- 已通过 `pnpm typecheck`、4 项计价引擎测试和 `pnpm build`；未触发 FedEx 外部调用。

## 2026-10-07：Open API 改为客户服务代码下单

- `POST /api/open/v1/shipments` 由内部 `supplier` 编号改为客户可见的 `service` 代码。旧 `supplier` 字段由全局 DTO 白名单校验拒绝，不再将供应商连接作为对外契约。
